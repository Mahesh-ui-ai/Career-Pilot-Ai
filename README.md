# 🚀 CareerPilot AI
### Your AI-Powered Career Pivot Coach

CareerPilot AI is an intelligent career guidance platform designed to help students and fresh graduates understand their skill gaps, build personalized learning plans, prepare for interviews, and take practical steps toward their dream careers.

## 🎯 Problem Statement

Students and fresh graduates often struggle to understand which skills employers expect, what they should learn next, and how to prepare for job applications and interviews.

CareerPilot AI brings these career preparation activities together in one AI-powered platform.

## ✨ Key Features

- **Resume Analyzer:** Analyze resumes and identify improvement areas.
- **Skill Gap Analysis:** Understand the skills needed for a target career.
- **Learning Roadmap:** Generate a personalized learning plan.
- **Portfolio Projects:** Get project recommendations to strengthen your profile.
- **Mock Interview:** Practise interviews and receive AI-powered feedback.
- **Progress Tracker:** Monitor completed and pending learning tasks.
- **Job Application Tracker:** Track applications and their statuses.
- **AI Career Action Agent:** Generate personalized next steps based on career goals and progress.
- **Voice Career Coach:** Interact with the career coach using voice dictation through Wispr Flow.

## 🧠 Technology Stack

- Python
- Streamlit
- Google Gemini API
- Wispr Flow
- AI-powered prompt engineering

## ⚙️ How It Works

1. The user enters their career goal and relevant information.
2. CareerPilot AI analyzes the user's career preparation needs.
3. The platform generates skill-gap insights and learning recommendations.
4. The user tracks learning progress and job applications.
5. The AI Career Action Agent recommends the next steps based on available progress information.

## 💻 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Mahesh-ui-ai/Career-Pilot-Ai.git
cd Career-Pilot-Ai
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment (Windows)

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure your Gemini API key

Create a `.env` file in the project directory and add your Gemini API key using the environment variable name expected by `app.py`.

Never commit your `.env` file or expose your API key.

### 6. Run the application

```bash
streamlit run app.py
```

CareerPilot AI combines career analysis, personalized learning, interview preparation, voice-based interaction, and AI-driven next-action recommendations in one platform.

Instead of simply giving career advice, it helps users turn career goals into actionable steps.
